_1 :: Field1 s t a b => Lens s t a b

Defined in lens-5.3.6:Control.Lens.Tuple

Access the 1st field of a tuple (and possibly change its type).

>>> (1,2)^._1
1
>>> _1 .~ "hello" $ (1,2)
("hello",2)
>>> (1,2) & _1 .~ "hello"
("hello",2)
>>> _1 putStrLn ("hello","world")
hello
((),"world")

This can also be used on larger tuples as well:

>>> (1,2,3,4,5) & _1 +~ 41
(42,2,3,4,5)

offset :: Rapids.Offset.Offset a => Double -> a

Defined in Rapids.Offset

join is optional (default 0) and selects how corners are treated (see <https://occt3d.com/dev/doc/refman/html/_geom_abs___join_type_8hxx.html GeomAbs_JoinType>):

> offset amount <join> <openfaces> solid|shape|path|path2d

openfaces :: [CInt] contains 1-based indices of faces (for solid) to remove from each solid component. Currently ignored for shape|path|path2d.

> offset amount solid   -- round corners
> offset amount 0 solid -- round corners (Arc)
> offset amount 1 solid -- Tangent
> offset amount 2 solid -- sharp corners (Intersection)
> offset 0.1 [1,2] unitCube -- round box without top and bottom
> offset 0.1 2 [1,2] unitCube -- sharp box without top and bottom
